# Harness documentation site

`apps/docs` is the public Fumadocs site served at harness.agentskit.io. It is its own package
(`@agentskit/harness-docs`) so Next and React 19 never reach the harness runtime, which renders its TUI with ink.

## Layout

- `apps/docs/content/docs/` — the curated MDX pages (get-started, concepts, configuration, guides, examples,
  reference). Pages under `reference/` are generated by `scripts/gen-docs-reference.mjs`; edit the generator, not
  the page.
- `apps/docs/app/(home)` — the landing page; its sections live in `apps/docs/components/home`.
- `apps/docs/app/docs` — the Fumadocs documentation layout and the catch-all page route.
- `apps/docs/app/api` — the search route (`apps/docs/app/api/search/route.ts`), a static index built from the
  content source.
- `apps/docs/app/for-agents` — the page that tells agents how to read the site.
- `apps/docs/components` — shared client components (shell, mermaid, pipeline and run-replay visuals).
- `apps/docs/lib` — `source.ts` (content loader), `shell.ts` (ecosystem shell data), `site.ts` (origin and base
  path), `stats.ts`.
- `apps/docs/types` — ambient types for the shell element.

## Change rules

- Keep numbers on the site derived from the repository (`scripts/lib/stats.mjs`), never typed by hand.
- Machine-readable surfaces (`llms.txt`, raw Markdown, stats) come from `scripts/build-docs-artifacts.mjs`.

## Check

`pnpm docs:build` builds the harness, writes the artifacts and builds the site; `pnpm docs:typecheck` type-checks it.
